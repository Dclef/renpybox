# RenpyBox 桌面版

RenpyBox 0.9.1 提供新的 Windows x64 桌面界面，包含翻译任务、Ren'Py 工具箱（27 项）、平行校对台、角色 / 世界观工作台、Agent 助手，以及提示词预览与编辑。支持浅色 / 深色主题与中英文界面（部分文案仍可能显示中文）。

## 下载与启动

从 [GitHub Releases](https://github.com/dclef/RenpyBox/releases) 下载对应资产：

| 文件 | 用途 |
| --- | --- |
| `RenpyBox-NewUI-0.9.1-x64.exe` | Windows 安装程序，推荐使用 |
| `RenpyBox-NewUI-0.9.1-x64.zip` | 免安装包，完整解压后运行其中的程序 |
| `RenpyBox_v0.9.1.zip` | 保留原界面的 Python 兼容包，供旧版用户更新 |

桌面版已附带运行环境，不需要额外安装 Python。正式包的应用配置与壳日志默认位于 `%APPDATA%\RenpyBox-newUI`；免安装包同样将应用配置保存在系统用户目录。

## 开始翻译

1. 在「接口管理」添加并测试翻译接口。免费 Google / Bing 无需 Key，但需要能访问对应服务的网络。
2. 在「项目设置」选择输入目录及语言，或进入工具箱的「一键翻译」选择游戏目录。
3. 完成文本准备后进入「翻译任务」，确认当前接口和输入、输出目录再开始翻译；可用「停止」「继续任务」「写入译文文件」「重翻失败项」。
4. 使用工具箱「检查与润色」或任务页「打开平行校对台」查看译文，确认后「写入译文文件」。校对不会自动改写游戏文件。
5. 需要时再「应用翻译到游戏」，并按需使用字体注入、添加语言入口或设置默认语言。

并发任务阈值与 RPM 等在「基础设置」调整。工具箱中带「需先选择游戏目录」提示的工具依赖当前项目；其他工具可在各自页面选择输入文件或目录。

## 从 Python 版迁移

Python 版的源码和原有入口继续保留。已安装的旧版本可以先更新到 Python 兼容版，再通过迁移提示打开桌面版下载页；也可以直接从发布页下载桌面版。

桌面版需要单独安装，迁移提示不会自动替换原 Python 应用或复制其配置。首次使用请重新确认项目目录和接口配置；保留原目录以便继续使用旧版。

## 更新和反馈

在「应用设置」检查桌面版更新。当前更新下载完整安装包（含大小与 SHA-256 校验），不提供差分下载，与旧 Python 版增量更新不同；下载校验通过后才允许安装。免安装用户也可手动下载并解压新版 ZIP。

遇到问题时打开「运行日志」，使用「导出日志」或「打开日志」获取对应文件，并附上复现步骤和版本号。
