这份说明补在 [README](README.md) 和 [UI 迁移检查记录](UI-REVIEW-2026-10-08.md) 之后，记录这一轮接到桌面壳上的行为和还没做完的部分。

## 后端怎么跟界面一起跑

开发时网页和 Electron 共用同一个 Python sidecar（默认端口 `9712`）。

- `npm run dev`：Vite、Electron 和后端一起起。后端由开发脚本托管。
- `npm run dev:web`：只起 Vite 和后端，用浏览器打开。
- 关掉 Electron 窗口不会杀掉后端。只有结束开发脚本（Ctrl+C）才会停。
- 已经有健康的后端时，后启动的进程只复用，不接管、不杀死。

只跑 `npm run dev:renderer` 不会启动 Python，界面会显示未连接。

## 这一轮接上的功能

| 能力 | 入口 | 说明 |
|---|---|---|
| Agent 助手 | 侧栏「Agent 助手」 | 选支持工具调用的接口后发消息、看思考和工具、确认后执行、停止或新建会话 |
| 应用更新 | 应用设置 → 关于与更新 | 复用 `VersionManager`：检查、下载、取消、安装、更新日志。源码运行时安装会打开发布页 |
| 工程绑定 | 项目设置 | 顶栏只显示已绑定的 Ren'Py 工程。选择带 `game/` 的目录才绑定；普通输入目录不会改写工程身份 |
| 术语表 | 侧栏「术语表」 | 原「项目词库」。正式词条和候选分开，保存到当前项目 |
| 禁翻表 | 侧栏 / 工具箱 | 读写配置 `text_preserve_data`，翻译时原样保留 |
| 称呼桥接 | 侧栏 / 工具箱 | 读写称呼词和桥接开关，处理「称呼 + 变量」 |
| 校对质量任务 API | `POST /api/proofreading/quality` | 后端可对选中缓存条目启动润色或校对，进度走 `TRANSLATION_UPDATE`。校对台界面还没有对应按钮 |

配色回到 `widget/ThemeTokens.py` 的 Windows 11 中性色和系统蓝。校对台、术语表、禁翻表、称呼桥接的数据区使用 Ant Design `Table`（`bordered`、`size="small"`），明暗主题跟着应用设置走。
