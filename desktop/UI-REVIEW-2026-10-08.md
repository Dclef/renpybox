## 视觉与编辑体验

- 统一页标题、留白、按钮与表单尺寸，使用一层表面和分隔线组织内容；浅色与深色主题使用同一套语义色。
- 接口采用分组行列表和内嵌编辑；工作台采用角色名单与右侧表单；校对采用原译并列；窄窗口调整为单列。
- 主题与应用设置保留在左下角，顶栏只提供窗口控制。动效保持短促，并支持系统减少动态效果设置。
- 离开编辑页面和系统关闭窗口时提示未保存内容；外部切换项目保留草稿，过期请求不能覆盖当前编辑。
- 导入文件期间禁止并行保存；词库候选重新导入不会自动晋升为正式术语。

## 持久化保护

工作台和词库复用 `ProjectAssetsRepository`，携带 `storage_key + revision`；跨项目或过期修改返回 409。资产先复制并落盘，成功后只发布资产与候选分区；保存失败不污染运行态，也不覆盖翻译进度。

校对写入检查项目缓存令牌和行版本，阻止运行任务、停止屏障或单条重译期间写入；批量冲突时整批不落盘。接口管理复用 `SecretStore` 和 `APITester`，失败保留旧配置与密钥，删除时同步接口引用。

## 操作说明

- 接口管理：新增接口，填写协议、地址和模型；编辑时密钥留空表示保留原值，清空需要显式勾选。
- 工作台：在世界观或角色卡修改资料，点击“保存修改”；用“提示词预览”检查已保存资料的命中结果。
- 校对台：点击译文编辑并保存；批量替换仅作用于当前页或已选行。修改保存在翻译缓存，写回游戏使用翻译页“导出译文”。
- 项目词库：导入或新增词条后保存到项目；候选需填写译文并勾选“确认候选”才成为正式词条。

## 本轮 API

| 接口 | 用途 |
|---|---|
| `POST /api/platforms` | 新建接口 |
| `PATCH / DELETE /api/platforms/{id}` | 编辑或删除接口 |
| `POST /api/platforms/{id}/activate`、`/test` | 激活或发起测试，测试结果经 `PLATFORM_TEST_DONE` 返回 |
| `GET / PATCH /api/workbench` | 读取或保存项目世界观与角色卡 |
| `POST /api/workbench/apply-drafts`、`/preview` | 应用已审核草稿、预览已保存资料的上下文 |
| `GET / PATCH /api/workbench/glossary` | 读取或保存正式词条与候选，保留未见过的新候选 |
| `GET /api/proofreading` | 分页和筛选真实缓存 |
| `PATCH /api/proofreading/item`、`POST /api/proofreading/replace` | 单条保存、纯文本批量替换 |
| `GET /api/settings/prompt-preview` | 静态提示词预览，不请求模型 |

详细字段由各路由的 Pydantic 模型与 FastAPI `/docs` 提供。接口返回的密钥均脱敏。
