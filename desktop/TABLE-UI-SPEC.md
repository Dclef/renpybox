# 桌面端表格组件规范

## 设计口径

校对台使用 Mantine Table；词库保留项目的 DataSheet。保留旧版的筛选、对照、编辑和保存流程。配色取 theme.ts / mantineTheme.ts 的语义变量；8px 圆角、横向分隔线，不使用斑马纹、毛玻璃或发光阴影。表头 12px、数据 13px，数字等宽。

## 数据与布局

- 术语表、禁翻表使用固定 40px 高虚拟列表，右侧编辑选中项；虚拟化来自已安装的 @tanstack/react-virtual。
- 校对台由服务端分页，支持 25 / 50 / 100 条；原文、译文允许换行，不按固定高度裁剪。原文与译文是普通单元格，不复用旧按钮样式。
- 词库的 grid 模板由同一组 columns 生成；校对台用原生 table / colgroup 对齐列。
- 校对台列为勾选、序号、原文、译文、状态、操作；完整文件路径放在选中行状态栏和行菜单中。窄窗口在表格内横向滚动，不隐藏操作。
- 长列表只在表格内容区滚动，表头固定。校对双击或 F2 打开双语弹窗，宽窗并排、窄窗上下排列；词库继续使用侧栏编辑。

## DataSheet 接口

文件：renderer/src/components/DataSheet.tsx。

| 参数 | 用途 |
| --- | --- |
| rows / getKey / columns | 数据、稳定行键和列定义 |
| selectedKey / onSelect | 当前编辑行；与批量勾选分开 |
| selection | 勾选集合、切换与全选，运行任务时禁用 |
| editor / editorClassName | 右侧编辑区 |
| virtual / rowHeight | 虚拟列表开关与估算行高 |
| scrollTopToken | 新增条目后回到列表顶部 |
| emptyText / footer | 空态与表尾 |

## 操作约束

1. 读取、保存失败展示真实错误，加载中不得显示“没有缓存”的结论。
2. 校对行以 cache_token 绑定项目，以 version 检查内容变化。版本冲突返回 409，不覆盖新译文。
3. 单击选行、Ctrl 增减、Shift 范围选择；上下键移动，Ctrl+A 全选当前页。双击/F2 编辑，Ctrl+Enter 保存；关闭弹窗或离开页面保留未保存保护。
4. 批量替换使用当前页或已选行；AI 校对与润色只使用当前页已选行，先确认范围与消耗。
5. 引擎运行、停止收尾或存在单条任务时，只读；取消质量任务后等待真实终态恢复操作。
6. 表格单元格作为文字渲染，禁止执行译文中的 HTML。
7. 右键以鼠标坐标定位，同一菜单供行尾按钮使用；贴边自动避让，滚动关闭。恢复重新翻译、复制原/译文、定位译文和有重试警告时的人工确认。
8. 重译只处理明确确认的所选行；取消等待已发出请求结束并保存成功结果，失败行保留原译文。
9. 导出先严格保存，再按现有 FileManager 格式写回输出目录；缓存保存失败时不得导出。
10. 只读快照只保留一个项目，以配置摘要与 JSON / SQLite / WAL 文件代次失效。普通翻页只检查当前页，问题筛选才检查候选集合；任何写入都重新读取并验证版本。

## 验证

scripts/check-ui.cjs 覆盖页面切换、缓存编辑、AI 操作、冲突提示、取消、报告恢复，以及 680 / 900 / 1000 / 1280 / 1920 五种宽度；tests/api/test_proofreading.py 验证临时 JSON / SQLite 缓存和项目边界。
