# 桌面端表格组件规范

## 设计口径

校对台、术语表、禁翻表都使用 Ant Design Table。保留各自的筛选、编辑和保存流程。配色取 theme.ts / antdTheme.ts 的语义变量；圆角走 token（SM8 / 默认10），横向分隔线，不使用斑马纹、毛玻璃或发光阴影。表头 12px、数据 13px，数字等宽。

## 数据与布局

- 术语表、禁翻表使用 antd `Table`（`bordered`、`virtual`、数字型 `scroll.x` / `scroll.y`，容器高度由 ResizeObserver 测量）。原文、译文、备注允许换行，不按固定行高截断。
- 词库在浏览器内分页，每页 25 / 50 / 100 条，默认 50。搜索回到第一页；删空最后一页时页码收回到仍有数据的页。序号列显示原始数据序号，筛选后仍对应该条。
- 校对台由服务端分页，支持 25 / 50 / 100 条；当前页再用 `virtual={true}`，避免整表灌入 DOM。原文、译文允许换行。
- 列宽用百分比或像素。术语表列为序号、原文、译文、类别、备注、命中数；禁翻表列为序号、原文、备注、命中数。
- 校对台列为勾选（rowSelection）、序号、原文、译文、状态、操作；完整文件路径放在选中行状态栏和行菜单中。窄窗口在表格内横向滚动，不隐藏操作。
- 长列表只在表格内容区滚动，表头固定。校对双击或 F2 打开双语弹窗，宽窗并排、窄窗上下排列。词库单击或 Enter 选行，双击或 F2 在对应单元格出现输入框；Enter 提交、Esc 取消、Tab 切到下一可编辑单元格。不使用右侧编辑侧栏或编辑 Modal。

## DataSheet 接口

文件：renderer/src/components/DataSheet.tsx。术语表与禁翻表共用 antd Table；页内 virtual + 本地分页，无侧栏编辑。

| 参数 | 用途 |
| --- | --- |
| rows / getKey / columns | 当前筛选结果、稳定行键和列定义；width 为百分比或像素；editKey 标记可编辑字段 |
| rowNumber | 原始序号（从 1 计），不随分页改变 |
| selectedKey / onSelect | 当前选中行，对应原始数据下标 |
| getEditValue / onCommitEdit | 读取与提交单元格草稿；只在保存到项目/设置后写盘 |
| editRequest | 外部请求开始编辑（新增后定位原文） |
| readOnly | 引擎忙或任务中禁止进入编辑 |
| label | 表格 aria-label，区分术语表和禁翻表 |
| resetPageToken | 变化时回到第一页（搜索） |
| emptyText / footer | 空态与表尾说明 |

## 操作约束

1. 读取、保存失败展示真实错误，加载中不得显示“没有缓存”的结论。
2. 校对行以 cache_token 绑定项目，以 version 检查内容变化。版本冲突返回 409，不覆盖新译文。
3. 单击选行；双击/F2 编辑单元格；上下键由浏览器行焦点承担。词库字段先到草稿，保存后生效。
4. 批量替换使用当前页或已选行；AI 校对与润色只使用当前页已选行，先确认范围与消耗。
5. 引擎运行、停止收尾或存在单条任务时，只读；取消质量任务后等待真实终态恢复操作。
6. 表格单元格作为文字渲染，禁止执行译文中的 HTML。
7. 右键以鼠标坐标定位，同一菜单供行尾按钮使用；贴边自动避让，滚动关闭。恢复重新翻译、复制原/译文、定位译文和有重试警告时的人工确认。
8. 重译只处理明确确认的所选行；取消等待已发出请求结束并保存成功结果，失败行保留原译文。
9. 导出先严格保存，再按现有 FileManager 格式写回输出目录；缓存保存失败时不得导出。
10. 只读快照只保留一个项目，以配置摘要与 JSON / SQLite / WAL 文件代次失效。普通翻页只检查当前页，问题筛选才检查候选集合；任何写入都重新读取并验证版本。
11. 术语/禁翻的 Excel、统计、扫描、翻译走 `/api/lexicon`，复用 JobManager 协作取消与引擎互斥；晚到结果核对方项目路径快照，不得覆盖用户后来改动。

## 验证

scripts/check-ui.cjs 覆盖页面切换、缓存编辑、AI 操作、冲突提示、取消、报告恢复、术语表与禁翻表的真实表格、单元格编辑、分页和编辑映射，以及 680 / 900 / 1000 / 1280 / 1920 五种宽度；tests/api/test_proofreading.py 与 tests/api/test_lexicon.py 验证临时缓存、Excel 与项目边界。
