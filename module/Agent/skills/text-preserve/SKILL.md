# 必须原样保留的东西

## 铁律

下面这些内容在译文中必须**逐字符**保持原样，位置可以移动，内容和写法不能改。

### Ren'Py 插值

```
[player_name]        → 变量插值
[points]              → 数值插值
[variable!t]          → 带转换标志（!t 是翻译，!u 是大写，!l 是小写，!c 是首字母大写）
[variable:.2f]        → 带格式说明
```

只翻译方括号**外面**的文字。方括号里的标识符改成中文变量名会让游戏报 `NameError`。

### 富文本标签

```
{b}粗体{/b}
{i}斜体{/i}
{color=#ff0000}红字{/color}
{size=+8}大字{/size}
{font=xxx.ttf}换字体{/font}
{k=...}  {w}  {p}  {nw}  {fast}
```

标签名、属性值、斜杠保持原样。可以翻译 `{b}...{/b}` 之间的文字。

### 转义与特殊字符

```
\"      转义的引号
\'      转义的单引号
\n      换行
\\      反斜杠本身
%       旧式格式化占位符
%s  %d  %1$s     printf 风格占位符
{ 和 }  在 f-string 上下文里
```

### Ren'Py 语句关键字

`with`、`pause`、`window`、`voice`、`play`、`show`、`scene`、`hide`、`jump`、`call`、`return`、`menu`、`label`、`if`、`elif`、`else`、`while`、`for`、`python`、`init`、`style`、`transform`、`screen`、`text`、`image`、`define`、`default`

这些出现在待译文本里时通常说明抽取错了，不要翻译，报告给用户。

## 需要保留的结构

### 换行数量

原文有几个换行，译文大致保持。少换行会把多行对话挤成一行，多换行会让文本框溢出。

### 空译文

原文本就是空的、或只有一个 `""`，译文保持为空。填上内容反而会出问题。

### old/new 配对

`old` 是原文、`new` 是译文的成对结构里，`old` 永远不能改。改 `old` 会让替换永远不命中，玩家看到的还是原文。

## 自检方法

译完一条，把它和原文并排看：

1. 方括号数量是否一致
2. 花括号标签是否成对且名字一致
3. 换行数是否一致
4. 是否有引号被吃掉

四条都过，再继续下一条。
