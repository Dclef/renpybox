# RenpyBox 路线图

## Agent 助手

- [x] Agent 逐批翻译时按批注入术语表、禁翻表与角色卡
- [x] Agent 写回译文时校验术语一致性，未按术语的条目退回待译
- [x] Agent 写回译文时应用译后替换规则
- [x] Agent 请求限流时退避重试，退避期间可立即停止
- [x] Agent 长会话上下文优先摘要压缩，失败才裁剪旧消息
- [x] 输出被截断时自动压低单批条目数，成功后再逐步放宽
- [x] 打开历史会话时恢复阶段与用量统计
- [x] Agent 翻译时保护 `[变量]` 与 `{标签}`，模型改坏则退回待译
- [x] Agent 状态栏显示可用输入预算、输出上限、消息上限与分项 token

## 翻译任务

- [x] 写入译文模板前做重复条目预检，只整理模板注入引起的重复，无法安全合并时标出文件与行号并停止写入
- [x] 术语提取与人名提取合并为「Agent 提取术语与人名」
- [x] 术语与人名提取支持断点续跑，显示复用块数与本轮请求数
- [x] 提取结果可先预览再加入词库草稿：只追加最多 20 条，保留原有词条，不自动保存
- [x] 提取取消后不再残留进行中状态

## Ren'Py 工具箱

- [x] 术语表支持勾选多条删除，翻页保留勾选，草稿不丢失
- [x] 字体一键替换写入前校验备份，不通过整体拒绝并给出可恢复路径
