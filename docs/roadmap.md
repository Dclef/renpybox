# 开发计划

## 工程质量

- [x] GUI 依赖钉死版本并生成全量锁文件，构建可复现
- [x] CI 质量门禁：全量测试 + Ruff 错误级检查 + 语法冒烟，发布被门禁阻塞
- [x] 翻译进度事件按窗口合并最新值，事件风暴不再挤占界面队列
- [x] 相同提示 2.5 秒内去重，连发错误聚合计数不再刷屏

## 自动更新

- [x] 更新只写入内容真正变化的文件，不再每版全量重写
- [x] 等待应用退出超时改为中止更新，不再带险继续
- [x] 更新器支持升级自身，修复旧版更新器永远收不到新版的问题
- [x] 更新日志记录各阶段耗时与写入字节数

## 应用界面

- [x] 支持中文与英文界面切换，主导航、工具箱入口和 RPA 打包页随应用语言显示
- [x] 补齐一键翻译、工作台、本地词库和工具详情页的英文文案

## 接口管理

- [x] 接口分组展示，条目显示名称、模型、接口格式和激活状态
- [ ] 添加接口向导：选平台、命名、填参数一次完成
- [ ] 分析、翻译、润色、校对各自指定接口

## 错误修复

- [x] 扫描占位符缺失、换行不一致、空字符串残留等常见译文问题
- [x] 重复的 old/new 字段默认注释保留，可配置为删除
- [x] 深度 lint 只报告问题，不自动改写脚本

## 更新翻译复用

- [x] 按原文把旧版本译文填入新版本的空条目，不受哈希变化影响
- [x] 支持只读预览，执行前自动备份目标译文目录

## 游戏模组注入

- [x] 一键把修改器（0x52-URM）注入游戏目录，可随时卸载
- [x] 注入画廊解锁器，游戏内通过自研 MOD 面板开启全部画廊或恢复游戏原本的画廊进度
- [x] MOD 面板提供修改器入口，不接管游戏原有快捷菜单

## RPA 打包

- [x] 自定义每包大小上限，把选定目录打包为多个独立 RPA 文件

## Agent 助手

- [x] 支持查询当前项目、列出 RPA 文件和扫描脚本错误
- [x] 经用户确认后解包当前项目中的 RPA 文件
- [x] 解包确认支持「不再询问」，勾选后自动执行（设置弹层可恢复确认）
- [x] 修复解包确认框点取消导致的应用闪退
- [x] 对话区视觉美化：用户气泡消息、Markdown 排版、顶栏设置弹层与空态卡片
- [x] 翻译完成后可把有效 old/new 译文生成运行时替换补丁，兼容攻略尾注和颜色标记
- [x] 可只读检查项目翻译阶段、缓存、工作台资产和质量状态，并建议下一步

## 一键翻译

- [x] 检测到 RPA 归档时自动解包，解包后自动衔接反编译
